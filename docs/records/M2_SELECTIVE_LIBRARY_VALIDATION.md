# M2 选择性内容库真机验收

> 日期：2026-08-10
>
> 设备：Xiaomi M2012K11AC，Android 13 / API 33，1080 × 2400
>
> 代码：`6cdca60 feat(library): add selective media discovery`

## 构建验证

在 Windows 环境使用仓库内 Gradle Wrapper 执行：

```text
gradlew.bat testDebugUnitTest lint assembleDebug
```

结果：全部通过，生成 Debug APK。随后使用 `adb install -r` 保留旧版应用数据覆盖安装。

## 验收前状态

- 设备已有 95 项系统音频；
- 旧版应用已获得 `READ_MEDIA_AUDIO`，尚未声明或获得 `READ_MEDIA_VIDEO`；
- 设备保留上一播放会话；
- 覆盖安装未清除 DataStore 与会话数据。

## 已验证

1. 启动后，旧版扫描到的 95 项音频全部进入待整理，没有自动成为首页内容；上一播放会话仍显示在底部。
2. 首页左上角为空，只保留搜索与管理；没有应用名、资料库标题、最近加入或来源状态。
3. 内容管理显示“补充本机授权”。点击后系统只请求照片和视频访问，没有重复请求音频权限。
4. 授权视频后发现 253 项内容：95 项音频与 158 项视频。权限状态为音频和视频均已授予。
5. 待整理页默认选中 95 项音频；158 项视频均保持未选，并显示类型、时长、分辨率和文件体积。
6. 收录音频后，95 项进入已收录，158 项视频继续留在待整理。文件夹内容集全部默认为已隐藏，没有自动铺满首页。
7. 手动将 `01 本編` 文件夹设为首页显示后，首页只出现该内容集及其 7 项音频，并保留 158 项待整理入口。
8. 使用一条未收录视频的文件名搜索，结果为“没有找到相关内容”，候选内容没有进入搜索。
9. 强制停止并冷启动后，95 项已收录、158 项待整理和首页文件夹选择均正确恢复。
10. 忽略一项视频后，待整理变为 157 项并出现已忽略入口；恢复后回到 158 项，已忽略入口消失。
11. 扫描、收录、冷启动和状态切换期间进程保持存活，AndroidRuntime 没有应用崩溃记录。

## 尚未覆盖

- 本轮没有在设备上准备包含同名字幕的独立 SAF 文件夹，因此文件夹递归扫描和自动字幕关联仍需专项真机样本；
- 没有覆盖撤销授权、目录失效、媒体被外部移动或删除后的恢复；
- 没有对超过 253 项媒体的扫描耗时、内存和滚动性能做压力测试；
- 普通播放器目前不显示视频画面，本轮只验证视频发现、筛选和持久化；
- 本轮沿用已有播放会话验证恢复入口，没有重新完整回归队列、睡眠定时和微光手势。

- 95 项音频已收录；
- 158 项视频保留在待整理；
- `01 本編` 文件夹设为首页显示；
- 没有已忽略内容。
