# OriginOS 媒体通知五槽位验证

## 方案

保留 Media3 默认原生媒体通知，在恰好三个动作时，将通知动作调整为：

`透明占位 / 上一项 / 播放或暂停 / 下一项 / 透明占位`

占位没有 PendingIntent。折叠动作索引同步改为 `1, 2, 3`；异步通知更新也应用同样处理。其他动作数量保持默认通知行为。没有替换 MediaStyle、自绘 RemoteViews 或改动播放会话命令。

## 真机结果

2026-09-05 在 vivo V2458A、Android 16（API 36）、OriginOS 上覆盖安装验证：

- 用户确认三个可见按钮居中，外侧空白符合预期。
- 截图确认原生标题、应用图标和单排按钮布局保留。
- 点击通知中央按钮，媒体会话从 PLAYING 切换为 PAUSED；再次点击恢复 PLAYING。
- 测试结束恢复暂停，保留内容与进度。

本次未覆盖其他厂商、Android 12、队列边界与通知折叠状态；该结果不代表所有系统使用相同布局。

## 经验

固定槽位中的空白占位是可验证的布局选择，不应预先排除。此前自定义通知的重复控件、留白与索引异常，并不能证明原生通知无法改善。优先用最小改动验证目标手机的实际排版。
