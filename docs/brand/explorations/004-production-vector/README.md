# 生产级矢量重建：品牌探索 004

> 状态：低节点技术实验，未作为当前 Android 视觉母版
>
> 记录日期：2026-08-08
>
> 视觉基准：[`003-prototype-3-master-body/`](../003-prototype-3-master-body/)

本轮不重新设计角色，而是在保持 003 已锁定轮廓、身体比例和五套表情观感的前提下，重建更少节点、更明确且便于维护的 SVG 几何。003 保留为不可变的像素拟合基准，004 保存生产路径候选。

后续对比确认这些结构变化仍能被肉眼察觉，因此当前 Android 平台资源直接使用 003，而不是用本目录覆盖视觉母版。本目录继续保留节点精简方法、误差数据和可维护性实验。

## 当前主标

![生产路径默认脸](01-default-smile.svg)

默认组合仍为原型 3 号身体与原型 2 号脸。本轮没有冻结默认脸的品牌决策，只冻结了这套候选的几何实现。

## 重建内容

- 外轮廓从带内外边界的填充路径，改为一条沿视觉中心线绘制的圆头描边；
- 两道内部褶皱从自动描摹轮廓，改为两条独立的圆头曲线；
- 直立眼睛改为几何胶囊，惊讶嘴改为圆形；
- 微笑、闭眼和波浪嘴按原型复杂度分别保留必要的曲线段数；
- 黑色背景与 `#FED552`、`#705D23`、`#FEF6E0` 三个角色色保持不变；
- 所有版本继续共用字节级一致的身体路径。

## 复杂度变化

下表统计 SVG 路径中的三次贝塞尔段数；`rect` 和 `circle` 作为几何图元不计入。

| 文件 | 003 | 004 | 说明 |
| --- | ---: | ---: | --- |
| `01-default-smile.svg` | 158 | 42 | 两个胶囊眼 + 一段微笑曲线 |
| `02-closed-eye-smile.svg` | 166 | 73 | 保留闭眼端部的细微粗细变化 |
| `03-surprised.svg` | 150 | 41 | 两个胶囊眼 + 一个圆形嘴 |
| `04-wink.svg` | 168 | 52 | 眨眼轮廓保留 10 段曲线 |
| `05-wave-mouth-extra.svg` | 167 | 57 | 波浪嘴保留 16 段曲线 |

统一身体本身由 003 的 `80 + 44` 段降为 `37 + 3 + 1` 段。

## 像素拟合结果

在 `1254 × 1254` 栅格上，以 003 为基准测量双向边缘距离：

| 区域 | IoU | 95% 边缘误差 |
| --- | ---: | ---: |
| 外轮廓 | 0.9627 | 1 px |
| 内部褶皱 | 0.9354 | 1 px |
| 默认脸 | 0.9665 | 1 px |
| 闭眼笑 | 0.9339 | 1.41 px |
| 惊讶 | 0.9667 | 1 px |
| 眨眼 | 0.9471 | 1.41 px |
| 波浪嘴 | 0.9534 | 1.41 px |

1.41 px 对应单个对角像素距离。局部最大差异集中在表情圆角或眨眼尖端，没有改变身体剪影。

## 小尺寸检查

使用浏览器直接栅格化 003 与 004，并在 `56 px`、`48 px`、`32 px` 下逐像素叠加：

- `56 px` 与 `48 px` 中，五个表情、两道褶皱和右侧掀角均保持完整，004 没有引入新的断裂；
- `32 px` 中，身体剪影仍然稳定，默认脸和惊讶脸仍可辨认；
- 闭眼、眨眼和波浪嘴的局部线条在 `32 px` 下低于一个物理像素，状态区分度下降；003 基准也存在相同行为，因此这不是路径重建回归；
- 004 应作为通用母版，不应为了 `32 px` 全局加粗。最小尺寸需要独立的光学校正版。
