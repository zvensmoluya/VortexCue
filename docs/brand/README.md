# VortexCue / 荧荧品牌探索

这里保存品牌方向、视觉草案及其形成过程。探索记录用于保留设计上下文，避免后续只看到结果而失去当时的判断依据。

这些文件默认不是正式发布资源，也不直接约束应用实现。某个方向正式采用后，仍需单独完成图标资源化、尺寸适配、设备验证和发布检查。

## 探索记录

- [`001-curtain-ghost/`](explorations/001-curtain-ghost/)：黄色窗帘幽灵；首个形成明确角色语言的未优化探索版。
- [`002-lifted-curtain-ghost/`](explorations/002-lifted-curtain-ghost/)：掀角窗帘幽灵；依据参考图手工重绘，并校正底边流线、褶皱方向与表情视觉轴的首组统一 SVG。
- [`003-prototype-3-master-body/`](explorations/003-prototype-3-master-body/)：暂定锁定原型 3 号身体，并将原型 2 号脸列为默认脸首选。
- [`004-production-vector/`](explorations/004-production-vector/)：低节点路径重建与像素误差实验；当前 Android 资源仍以 003 为视觉母版。

## 平台资源

- [`platform/android/`](platform/android/)：Android Adaptive Icon、圆形入口、Android 13+ 单色层与系统 Splash 适配记录。
